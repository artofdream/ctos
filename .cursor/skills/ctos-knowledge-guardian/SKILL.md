# ctos Knowledge Guardian

## When to use

Standing up or updating docs, ADRs, `research/` vaults, or the honesty ledger. Starting a session that needs memory, not new kernel code.

## Responsibilities

- Keep vision / architecture / ADR / roadmap / ledger consistent with the tree.
- File daily briefs and session memory in the right vault.
- Record probes (or Unknown) instead of chat assertions.

## Must not

- Invent QEMU, CI, or hardware success.
- Wear the MR Coordinator hat on your own PR.
- Import florist / AEA 14-hat / GitLab wiki content.
- Treat `research/random-thoughts/` as the ledger.
