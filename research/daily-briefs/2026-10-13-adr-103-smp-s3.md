# 2026-10-13 — ADR-103: SMP slice S3

- **Sponsor go** for S3 at $0 (2026-10-13 about 23:37 CEST), effective on the #156 merge (23:38 CEST); relayed by DSO.
- **TABLES type-enforced:** page-table storage private to `paging::tables`; every writer takes `&mut TablesGuard`, only obtainable from `lock_tables()` (IRQs masked while held).
- **Broadcast TLBI:** both TLB helpers now `dsb ishst; tlbi vmalle1is / vaae1is; dsb ish; isb`. Default single-core smoke unchanged.
- **Cross-core probe:** core 0 maps a page, core 1 reads it, core 0 unmaps it, core 1 faults on its own vectors: `smp: xtlb unmap cpu0 → cpu1 fault`.
- **Negative:** `local-tlbi-leak-probe` keeps local TLBI; core 1 still reads the page: `smp: xtlb leak`. Reproduced 27/27 on the box (QEMU soft TLB); the smoke fails loudly if a future QEMU stops reproducing it.
- **Not claimed:** SMP safety; EL0 on core 1; ASIDs; unlocked reads; real hardware. ADR-091 rev 4 stays one core.
- **Next (proposed, needs a go):** S4 — ASID allocator with generation, PerCpu via `TPIDR_EL1`, first EL0 on core 1 with each isolation probe re-run there.
