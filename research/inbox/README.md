# Inbox

Fleeting captures waiting for triage.

This folder is a holding area, not a vault of record. After a pass:

- keep the note as session scratch → `research/random-thoughts/`
- promote a durable claim → `docs/` (vision, ADR, ledger, or FR/NFR — with a GitHub issue if you need a new ID)
- drop it if it was noise

Do not treat inbox notes as the honesty ledger. Do not put secrets here.

Copy [../templates/inbox-note.md](../templates/inbox-note.md) when you want a thin heading.
